Generate VS Code snippets from code patterns in your project

## Install

```bash
npm install -g ai-snippet
```

## Usage

```bash
npx ai-snippet ./src/
npx ai-snippet ./lib/components/
```

## Setup

```bash
export OPENAI_API_KEY=sk-...
```
